# How to setup
## Get source code
```sh
git clone https://github.com/mshogulina/manix-dashboard.git
```
## Setup environment
```sh
python -m venv venv
source venv/Scripts/activate
http://127.0.0.1:8000
```

## Create App
```sh
python manage.py startapp webapp
```

## Start:
```sh
python manage.py runserver
```
